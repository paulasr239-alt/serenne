# Serenne Joalheria

**Elegância em cada detalhe.**

## Sobre o projeto

A Serenne é uma loja virtual de joias desenvolvida como atividade do curso técnico de Tecnologia da Informação do Senac.

O site permite visualizar produtos, realizar compras e administrar o estoque da loja.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- PHP
- MySQL
- PDO
- Git e GitHub

## Funcionalidades

- Cadastro e login de usuários.
- Busca e filtro de joias.
- Página de detalhes dos produtos.
- Carrinho de compras.
- Controle de estoque.
- Finalização de pedidos.
- Pagamento simulado por PIX, Boleto e Cartão.
- Painel administrativo.
- Cadastro, edição e exclusão de produtos.
- Visualização dos pedidos.
- Validação de formulários com JavaScript.
- Confirmação de exclusão de produtos.

## Como executar o projeto

1. Instale o XAMPP.
2. Coloque a pasta serenne dentro da pasta htdocs.
3. Inicie o Apache e o MySQL.
4. Importe o arquivo database/schema.sql no phpMyAdmin.
5. Crie o arquivo .env seguindo o modelo .env.example.
6. Acesse http://localhost/serenne.

## Acesso administrativo

1. Realize um cadastro na loja.
2. Abra o phpMyAdmin.
3. Acesse o banco de dados serenne.
4. Abra a tabela usuarios.
5. Altere o tipo do usuário de cliente para admin.
6. Saia da conta e entre novamente.
7. Acesse a opção Administração.

## Segurança

As senhas são protegidas por hash, os dados de conexão ficam no arquivo .env e o painel administrativo possui acesso restrito.
